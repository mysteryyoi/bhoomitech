# Boomitech placeholder

A responsive, static coming-soon page for **boomitech.in**. No build step or JavaScript is required.

## Preview

From this directory run `python -m http.server 4173 --directory dist` and open http://localhost:4173.

## Hosting

Upload the contents of `dist` to any static web host. Connecting `boomitech.in` requires access to the domain's DNS and hosting configuration. The Sites preview is separate from that domain.

The page does not collect visitor information. Google Fonts is optional; system fonts are used if it is unavailable. The illustration and favicon are included locally.
